# Social Media Skill — 社交媒体内容

## Goal
From a topic or announcement, produce platform-optimized social media posts with a content calendar, hashtag strategy, and engagement hooks.

## Available Tools
Write, search_web, docwriter skill.

## Workflow

### Step 1: Platform & Audience
Clarify with the user:
- Target platforms: LinkedIn, Twitter/X, WeChat, Instagram, TikTok, etc.
- Audience: B2B, B2C, developer, executive, general
- Goal: awareness, engagement, lead generation, thought leadership
- Brand voice: professional, casual, witty, educational

### Step 2: Content Strategy
For each platform, adapt:
- **Length**: platform character limits
- **Format**: text, image, carousel, video, thread
- **Tone**: platform-appropriate voice
- **CTA**: platform-appropriate call to action
- **Timing**: best posting times for the audience

### Step 3: Post Generation
For each platform, produce:
- **Hook**: first line that stops the scroll
- **Body**: value-packed content, scannable
- **Visual suggestion**: image concept, chart, or screenshot
- **Hashtags**: 3-5 relevant, researched hashtags
- **Engagement prompt**: question or call to action

### Step 4: Content Calendar
If doing a series:
- Map posts to a timeline (daily/weekly)
- Mix content types: educational, promotional, engagement
- Identify key dates and events to align with
- Balance platform mix

### Step 5: Multi-Platform Adaptation
Take a core message and adapt it:
- **LinkedIn**: professional, longer-form, 1-2 paragraphs
- **Twitter/X**: punchy, thread format, hashtag-heavy
- **WeChat**: visual-first, conversational, emoji-friendly
- **Instagram**: visual concept + caption, story format

## Quality Rules
- First line must be scroll-stopping — test it aloud
- Hashtags must be researched, not generic (#marketing is useless)
- One CTA per post — don't confuse the reader
- Date-specific content must include the date
- Never fabricate engagement metrics or follower counts
